# IronForge Hardware

E-commerce storefront for hardware with inventory and user (team account) management.

**Stack:** Vite · React 19 · TypeScript · Tailwind CSS v4 · [motion](https://motion.dev) · ogl (WebGL)

Animation primitives in `src/components/fx` follow [React Bits](https://reactbits.dev) patterns
(SplitText, ShinyText, CountUp, SpotlightCard, TiltCard, Magnetic, Aurora).

```bash
npm install
npm run dev
```
